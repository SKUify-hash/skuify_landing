Политика конфиденциальности

Редакция от: 11 мая 2026 г.

Оператор персональных данных: ИП Досчанов Расулбек Дилмурод ўғли, ПИНФЛ 51007056590048, Республика Узбекистан

1. Общие положения

Настоящая политика описывает, какие данные собирает сервис SKUify (Telegram-бот @SKUify_bot), как они используются и защищаются, в соответствии с Законом Республики Узбекистан «О персональных данных» № ЗРУ-547 от 02.07.2019.

2. Какие данные мы собираем

Данные Источник Цель сбора
Telegram ID, username, имя Telegram Bot API (автоматически при старте бота) Идентификация пользователя, учёт генераций, поддержка
Загружаемые изображения Пользователь загружает вручную Генерация карточек товаров — единственная цель
История запросов Формируется автоматически при использовании бота Учёт тарификации, техническая поддержка
Платёжные данные Передаются платёжными системами Click / Payme Подтверждение оплаты, учёт баланса

Мы не собираем: номера карт, CVV, PIN-коды. Все платёжные операции обрабатываются исключительно на защищённых серверах Click Business и Payme Business.

3. Цели обработки данных

  • Предоставление услуг по генерации карточек товаров.
  • Учёт бесплатных и платных генераций.
  • Обработка платежей через Click и Payme.
  • Техническая поддержка пользователей.
  • Улучшение качества Сервиса (в обезличенном виде).

4. Обработка изображений

Загруженные фотографии товаров:

  • Передаются стороннему API для анализа и генерации изображений.
  • Не хранятся постоянно — удаляются с наших серверов после завершения генерации.
  • Не используются для обучения моделей ИИ.

5. Передача данных третьим лицам

Данные могут быть переданы только в следующих случаях:

  • Сторонний API генерации изображений — для обработки загруженных фотографий.
  • Click Business / Payme Business — платёжные данные для обработки транзакций.
  • Государственные органы — по законному требованию согласно законодательству РУз.

Мы не продаём и не передаём данные рекламным сетям, агрегаторам или иным коммерческим третьим лицам.

6. Сроки хранения данных

  • Изображения — удаляются после завершения генерации (в течение нескольких минут).
  • Telegram ID, история операций — хранятся в течение срока действия аккаунта в боте.
  • Данные об оплатах — хранятся 3 года в соответствии с требованиями бухгалтерского учёта РУз.

7. Права пользователя

В соответствии с Законом РУз «О персональных данных» вы вправе:

  • Получить информацию о хранимых данных — обратитесь через @SKUify_bot.
  • Запросить удаление своих данных — мы удалим всё в течение 7 рабочих дней (кроме данных, обязательных к хранению по закону).
  • Отозвать согласие на обработку — прекратите использование бота и направьте запрос на удаление.

8. Безопасность

Для защиты данных применяются:

  • Шифрование данных при передаче (HTTPS / TLS).
  • Ограниченный доступ к базе данных (только авторизованный технический персонал).
  • Регулярное обновление ПО и мониторинг безопасности.

9. Файлы cookie и аналитика

Лендинг-страница SKUify не использует файлы cookie и не подключает сторонние системы аналитики. Данные о посещениях не собираются.

10. Изменения политики

При существенных изменениях пользователи будут уведомлены через бот. Актуальная версия всегда доступна на этой странице.
